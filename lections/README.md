## Как заниматься. Несколько важных правил

1.  (**Обязательно**) Советую прежде всего медленно и вдумчиво читать лекцию целиком, а не по частям. Связки между темами тут несущие.
2.  (Желательно) Решить все задачи дня, по порядку, каждую отдельным файлом.
3. (**Обязательно**) Зачётную задачу сделать самому. Её одну нельзя списывать, остальное можно.
4. Закрыть день коммитом (по желанию, конечно же).

А теперь правила, на которых всё держится:

* **3-4 часа в день, каждый день.** Главные во время занятий совершать небольшие перерывы.
* **Правило 20 минут.** Бьёшься сам 20 минут, потом ищешь помощь. Не раньше и не позже.
* **Ошибки компилятора читать, а не пугаться!!** Первая строка ошибки самая важная, остальные обычно её следствия.

Три способа всё испортить: 
1. Списывать решение не промучившись самому...
2. Пропустить день «потому что устал». 
3. Пропущенный день почти всегда становится двумя, а то и тремя, в зависимости от темы)

## Как читать файлы

Лекции написаны под [Obsidian](https://obsidian.md/): с коллаутами, ссылками вида `[[02-tipy-i-vetvleniya]]` и формулами.

На GitHub всё читается нормально, но часть коллаутов покажется обычными цитатами, а внутренние ссылки работать не будут. Если хочется полного вида и графа связей между лекциями, клонируйте репозиторий и откройте папку как хранилище Obsidian:

```bash
git clone https://github.com/Stalagghh/cpp-learning.git
```

## Ресурсы

* [learncpp.com](https://www.learncpp.com/): лучший бесплатный учебник, главы 1-8 закрывают первую неделю
* [Основы C++, хендбук Яндекс Образования](https://education.yandex.ru/handbook/cpp): второй источник, подключается в пятой лекции, маршрут на первую неделю 5.1, затем 2.1, 2.2 и 2.3
* [acmp.ru](https://acmp.ru/) и [e-olymp.com](https://www.e-olymp.com/): задачи с автоматической проверкой
* [cppreference.com](https://en.cppreference.com/): справочник, по которому я занимаюсь
* [godbolt.org](https://godbolt.org/): посмотреть, во что компилятор превращает ваш код
