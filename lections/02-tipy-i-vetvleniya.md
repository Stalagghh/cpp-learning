# День 2 — Типы, операторы, ветвления

> [!abstract] О чём эта лекция
> Переменные и их типы. Почему `5 / 2` даёт 2, а не 2.5. Как программа принимает решения через `if`, `switch` и тернарный оператор. Здесь же — ловушки, на которых спотыкаются все без исключения.

## 1. Переменная и зачем ей тип

Переменная — это именованный кусок памяти. Объявление выглядит так:

```cpp
int age = 19;
```

- `int` — **тип**: сколько байт занять и как трактовать лежащие там биты;
- `age` — имя;
- `19` — начальное значение.

В памяти всё лежит битами. Одна и та же цепочка нулей и единиц может означать число, символ или кусок дробного числа — разницу делает исключительно тип. Компилятор по типу решает, сколько памяти выделить, какую машинную инструкцию использовать для сложения и что можно с этой переменной делать.

C++ — язык со **статической типизацией**: тип задаётся при объявлении и не меняется никогда. Это строгость, которая ловит ошибки на этапе компиляции, а не в проде.

### Основные типы

| Тип | Размер | Что хранит | Диапазон |
|---|---|---|---|
| `int` | 4 байта | целые | ≈ ±2,1 млрд |
| `long long` | 8 байт | целые | ≈ ±9,2 · 10¹⁸ |
| `double` | 8 байт | дробные | огромный, но с потерей точности |
| `char` | 1 байт | один символ | 256 значений |
| `bool` | 1 байт | истина/ложь | `true` / `false` |

Точный максимум `int`: **2 147 483 647**, то есть $2^{31}-1$. Узнаёшь степень двойки? Из 32 бит один уходит на знак, остаётся 31 бит на величину, и ещё единица вычитается, потому что ноль тоже занимает место.

> [!warning] Переполнение
> ```cpp
> int x = 2147483647;
> x = x + 1;   // станет -2147483648
> ```
> Число не «упирается в потолок», оно **проваливается в минимум**, как одометр, перещёлкивающий с 999999 на 000000. Компилятор об этом не предупредит и программа не упадёт — просто дальше пойдут неверные числа. Факториал уже от 13 не влезает в `int`. Если ждёшь больших значений — бери `long long`.

### `char` — это на самом деле число

```cpp
char c = 'A';
std::cout << c;          // A
std::cout << (int)c;     // 65
```

В памяти лежит число 65 — код символа в таблице ASCII. Тип `char` просто говорит «показывай это как символ». Отсюда фокус, который пригодится позже:

- `'A'` = 65, `'a'` = 97, `'0'` = 48;
- `'7' - '0'` = 55 − 48 = **7**. Так символ цифры превращается в саму цифру.

Кавычки различаются принципиально: `'A'` — один символ (`char`), `"A"` — строка из символа и невидимого нуля-терминатора. Не взаимозаменяемы.

### `bool`

Хранит `true` или `false`. При выводе печатается как 1 и 0. В обратную сторону: **любое ненулевое число считается истиной**, ноль — ложью. Это источник знаменитого бага с `=` вместо `==`, о нём ниже.

### Неинициализированная переменная

```cpp
int x;                 // значение — мусор, что было в памяти
std::cout << x;        // напечатает случайное число
```

C++ не обнуляет переменные автоматически ради скорости. Читать неинициализированную переменную — неопределённое поведение: сегодня работает, завтра нет. **Всегда задавай начальное значение.** Флаг `-Wall` про такое предупреждает.

## 2. Ввод и вывод

```cpp
#include <iostream>

int main() {
    int a;
    std::cout << "Введите число: ";
    std::cin >> a;
    std::cout << "Вы ввели " << a << std::endl;
    return 0;
}
```

Стрелки показывают направление потока данных: `cout <<` — данные текут в вывод, `cin >>` — из ввода в переменную. Путать их — классика первой недели.

`cin` пропускает пробелы и переводы строк, поэтому `std::cin >> a >> b;` спокойно прочитает два числа хоть через пробел, хоть через Enter.

## 3. Арифметика и главная ловушка

Операторы: `+`, `-`, `*`, `/`, `%`.

### Целочисленное деление

```cpp
5 / 2      // 2, а не 2.5
1 / 2      // 0
-7 / 2     // -3 (дробная часть отбрасывается, к нулю)
```

**Правило:** если оба операнда целые, результат тоже целый. Дробная часть не округляется, а **отбрасывается**. `9 / 10` — это ноль, и это не ошибка компилятора, это язык так устроен.

> [!important] Почему так
> Тип результата определяется типами операндов, а не тем, что «должно получиться математически». `int / int` обязан дать `int`, потому что решение о типе принимается на этапе компиляции, задолго до того, как станут известны сами значения.

### Остаток `%`

```cpp
5 % 2      // 1
10 % 5     // 0
7 % 10     // 7
```

Работает только с целыми. Формула, связывающая всё воедино:

$$\text{делимое} = \text{частное} \times \text{делитель} + \text{остаток}$$

Проверка: $5 = 2 \times 2 + 1$. ✓

Две операции, `/` и `%`, — рабочая лошадка первых недель:

- `n % 2 == 0` → число чётное;
- `n % 10` → последняя цифра;
- `n / 10` → число без последней цифры;
- `sec / 60` и `sec % 60` → минуты и секунды.

> [!warning] Деление на ноль
> `a / 0` для целых — не «бесконечность» и не исключение, а **аварийное завершение программы** (SIGFPE). Проверять делитель обязан ты сам, до деления. Именно поэтому в задаче про калькулятор отдельным пунктом стояла проверка нуля.

### Как получить дробный результат

```cpp
double r = 5 / 2;              // 2.0 — деление УЖЕ произошло в целых, поздно
double r = 5.0 / 2;            // 2.5 — один операнд дробный
double r = (double)a / b;      // 2.5 — явное приведение типа
```

Достаточно, чтобы **один** операнд был дробным: второй автоматически повысится до `double`. В первой строке ошибка тонкая — присваивание в `double` происходит уже после того, как деление вернуло 2.

### Приведение типов

```cpp
double d = 3.9;
int n = (int)d;    // 3 — дробная часть отброшена, НЕ округление
```

Приведение к `int` всегда отбрасывает дробную часть. Чтобы округлить по правилам, нужен `std::round` из `<cmath>`.

### Инкремент

`i++` — то же, что `i = i + 1`. Аналогично `i--`, `i += 5`, `i *= 2`, `i /= 2`. Сокращения, которые в циклах используются постоянно.

## 4. Сравнения и логика

| Оператор | Смысл |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `>` `<` `>=` `<=` | больше, меньше, и с равенством |

Результат сравнения — `bool`.

> [!warning] `=` против `==`
> `=` — присваивание, `==` — сравнение. `if (x = 5)` не сравнивает, а **записывает** 5 в `x`, а затем считает результат истиной (5 ≠ 0). Условие всегда истинно, и переменная испорчена. Ошибка компилируется молча — только `-Wall` намекнёт.

### Логические операторы

- `&&` — И: истина, когда истинны оба;
- `||` — ИЛИ: истина, когда истинно хотя бы одно;
- `!` — НЕ: переворачивает.

```cpp
if (age >= 18 && age <= 65)         // в диапазоне
if (day == 6 || day == 7)           // выходной
if (!found)                          // не найдено
```

Диапазон **нельзя** писать как в математике: `18 <= age <= 65` скомпилируется, но даст чушь. Сначала вычислится `18 <= age` → `true` (то есть 1), потом сравнится `1 <= 65` → всегда истина. Только через `&&`.

### Ленивое вычисление

```cpp
if (b != 0 && a / b > 2)
```

Если `b == 0`, левая часть ложна, и правая **не вычисляется вообще** — деления на ноль не произойдёт. Для `&&` вычисление останавливается на первой лжи, для `||` — на первой истине. Приём используют постоянно: сначала проверка безопасности, потом опасное действие.

## 5. Ветвления

### `if` / `else if` / `else`

```cpp
if (n > 0) {
    std::cout << "положительное";
} else if (n < 0) {
    std::cout << "отрицательное";
} else {
    std::cout << "ноль";
}
```

Проверки идут сверху вниз, **срабатывает первая подошедшая**, остальные пропускаются. Поэтому порядок условий важен: если поставить самое широкое условие первым, узкие уже никогда не выполнятся.

> [!warning] Три ловушки `if`
> **Лишняя точка с запятой:** `if (x > 0);` — тело пустое, следующий блок выполнится безусловно. Компилятор молчит.
> **Фигурные скобки:** без них к `if` относится только одна следующая строка. Вторая выполнится всегда, независимо от условия. Ставь скобки всегда, даже для одной строки.
> **Сравнение `double` через `==`:** `0.1 + 0.2 == 0.3` — **ложь**. Дробные хранятся приближённо. Сравнивать через разность: `fabs(a - b) < 0.0001`.

### `switch`

Когда сравниваешь одну переменную с набором конкретных значений:

```cpp
switch (op) {
    case '+':
        std::cout << a + b;
        break;
    case '-':
        std::cout << a - b;
        break;
    default:
        std::cout << "неизвестная операция";
}
```

> [!important] `break` обязателен
> Без `break` выполнение **проваливается** в следующий `case` и идёт дальше, игнорируя все проверки. Забытый `break` — самая частая ошибка в `switch`. Иногда провал делают нарочно (несколько `case` подряд с одним телом), но тогда это пишут осознанно.

Ограничение: `switch` работает только с целыми и `char`, только с точным равенством. Диапазоны и дробные — не сюда.

### Тернарный оператор

```cpp
int max = (a > b) ? a : b;
```

Читается: «если `a > b`, то `a`, иначе `b`». Компактная замена короткого `if/else`, когда надо **выбрать значение**. Вкладывать друг в друга не стоит — читаемость умирает мгновенно.

## 6. Область видимости

```cpp
if (x > 0) {
    int y = 5;
}
std::cout << y;    // ОШИБКА: 'y' was not declared in this scope
```

Переменная живёт от объявления до закрывающей скобки `}` своего блока, потом уничтожается. Правило: объявляй в самой узкой области, где переменная нужна. Меньше живёт — меньше шансов случайно испортить.

## Итог одной страницей

- Тип решает, сколько памяти занять и как трактовать биты. Задаётся навсегда при объявлении.
- `int` = 4 байта, максимум $2^{31}-1$. Переполнение молча уводит в минус.
- `int / int` = `int`, дробная часть отбрасывается. Нужен дробный результат — сделай один операнд `double`.
- `n % 10` — последняя цифра, `n / 10` — обрезать последнюю. Основа половины задач Дня 3.
- Деление на ноль в целых роняет программу. Проверяй сам.
- `=` присваивает, `==` сравнивает. Диапазон — только через `&&`.
- `&&` и `||` ленивы: проверка безопасности слева, опасное действие справа.
- Скобки в `if` ставь всегда. `break` в `switch` не забывай. Точку с запятой после `if (...)` не ставь.
